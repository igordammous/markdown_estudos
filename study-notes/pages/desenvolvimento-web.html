1. Internet, Web e HTML

1.1 Internet e World Wide Web

A Internet é a infraestrutura de redes que permite a comunicação entre dispositivos. A World Wide Web (WWW ou Web) é um dos serviços que utiliza essa infraestrutura para disponibilizar e consultar documentos e recursos interligados.

Internet e Web não são sinônimos: a Internet pode existir sem a Web, mas a Web depende da infraestrutura da Internet para funcionar.

A Web é uma iniciativa de recuperação de informações hipermídia que busca oferecer acesso universal a um grande conjunto de documentos. Esses documentos podem conter textos, hipertextos, imagens, sons e vídeos. O acesso normalmente é feito por meio de um navegador web, como Google Chrome, Mozilla Firefox ou outros.

1.2 O que é HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). É a linguagem de marcação utilizada para publicar conteúdo na Web e definir o significado e a estrutura desse conteúdo.

  • HTML: organiza e estrutura o conteúdo.
  • CSS: descreve a apresentação visual, como cores, fontes, espaçamentos e posicionamento.
  • JavaScript: acrescenta comportamento e interatividade à página.

O termo hipertexto está relacionado aos links que conectam páginas dentro de um mesmo site ou entre sites diferentes. Os links são uma parte fundamental da Web.

1.3 Estrutura básica de um documento

Um documento HTML é composto por elementos identificados por tags. A estrutura mínima de uma página pode ser representada assim:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha primeira página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Minha primeira página HTML.</p>
</body>
</html>
  • <!DOCTYPE html> informa ao navegador que o documento utiliza HTML5.
  • <html> é o elemento raiz da página; o atributo lang informa o idioma.
  • <head> contém metadados e informações que não são o conteúdo principal exibido.
  • <meta charset="UTF-8"> define a codificação de caracteres.
  • <title> define o título mostrado na aba do navegador.
  • <body> contém o conteúdo apresentado ao usuário.

2. Elementos, tags e atributos

HTML utiliza marcação para indicar ao navegador como interpretar textos, imagens e outros conteúdos. Um elemento geralmente é formado por uma tag de abertura, conteúdo e tag de fechamento.

<p>Este é o conteúdo de um parágrafo.</p>

Em geral, tags são escritas entre os sinais < e >. Os nomes dos elementos não diferenciam letras maiúsculas de minúsculas, mas recomenda-se utilizar letras minúsculas.

Alguns elementos, como <img> e <br>, não possuem tag de fechamento. São elementos vazios.

Atributos fornecem informações adicionais ao elemento e são escritos na tag de abertura, normalmente no formato nome="valor".

<p class="destaque" id="aviso">Texto destacado</p>

3. Listas

As listas organizam informações relacionadas. Os materiais apresentam três tipos principais: listas ordenadas (<ol>), não ordenadas (<ul>) e de definição (<dl>).

3.1 Listas ordenadas e não ordenadas

Lista ordenada: utiliza <ol> e apresenta itens em uma sequência numerada ou ordenada.

<ol>
    <li>Planejar a página</li>
    <li>Criar o HTML</li>
    <li>Testar no navegador</li>
</ol>

Lista não ordenada: utiliza <ul> e apresenta itens sem estabelecer uma ordem numérica.

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Em ambos os casos, cada item é definido pelo elemento <li>. Listas também podem ser aninhadas dentro de outros itens.

3.2 Listas de definição

O elemento <dl> representa uma lista de descrições. Cada termo é indicado por <dt> e sua descrição por <dd>.

<dl>
    <dt>HTML</dt>
    <dd>Linguagem de marcação para estruturar conteúdo.</dd>
    <dt>CSS</dt>
    <dd>Linguagem utilizada para definir a apresentação visual.</dd>
</dl>

4. Imagens

O elemento <img> incorpora uma imagem à página. Ele utiliza atributos para indicar o arquivo e fornecer uma descrição textual.

<img src="imagens/paisagem.jpg"
     alt="Paisagem de montanhas ao entardecer"
     width="600">
  • src: caminho ou endereço do arquivo de imagem.
  • alt: texto alternativo que descreve a imagem; é importante para acessibilidade e também pode ser exibido quando a imagem não carrega.
  • width: largura da imagem.
  • height: altura da imagem, quando definida.

O caminho de src pode ser relativo ao arquivo HTML ou um endereço absoluto. Ao organizar o projeto, mantenha os arquivos de imagem em uma pasta, por exemplo, imagens/.

<!-- Imagem em uma subpasta do projeto -->
<img src="imagens/logo.png" alt="Logotipo da empresa" width="180">

5. Links e navegação

O elemento <a> cria um hiperlink. O atributo href informa o destino do link.

<a href="https://www.google.com">Acessar o Google</a>

Os links podem apontar para páginas externas, arquivos do próprio projeto, endereços de e-mail ou partes específicas da mesma página.

<!-- Página externa -->
<a href="https://www.w3.org/">W3C</a>

<!-- Outra página do projeto -->
<a href="contato.html">Contato</a>

<!-- Seção da própria página -->
<a href="#referencias">Ir para referências</a>

<!-- E-mail -->
<a href="mailto:contato@exemplo.com">Enviar e-mail</a>

Para abrir um destino em outra aba, pode-se utilizar target="_blank". Recomenda-se combiná-lo com rel="noopener noreferrer".

<a href="https://www.google.com"
   target="_blank"
   rel="noopener noreferrer">
   Abrir em nova aba
</a>

Uma imagem também pode funcionar como link, colocando o elemento <img> dentro de <a>, como no exemplo apresentado na aula:

<a href="https://www.google.com">
    <img src="imagens/google.png"
         alt="Acessar o Google"
         width="200">
</a>

6. Tabelas

Tabelas são utilizadas para apresentar dados organizados em linhas e colunas. O elemento <table> cria a tabela; <tr> define uma linha; <th> define uma célula de cabeçalho; e <td> define uma célula de dados.

<table>
    <caption>Alunos cadastrados</caption>
    <thead>
        <tr>
            <th>Matrícula</th>
            <th>Nome</th>
            <th>Curso</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>001</td>
            <td>Ana</td>
            <td>ADS</td>
        </tr>
        <tr>
            <td>002</td>
            <td>Bruno</td>
            <td>ADS</td>
        </tr>
    </tbody>
</table>
  • <caption>: título ou legenda da tabela.
  • <thead>: agrupa as linhas de cabeçalho.
  • <tbody>: agrupa o conteúdo principal.
  • <tfoot>: pode agrupar linhas de resumo ou rodapé.

6.1 Colspan e rowspan

Os atributos colspan e rowspan permitem que uma célula ocupe mais de uma coluna ou linha, respectivamente.

<table border="1">
    <tr>
        <th colspan="2">Cadastro</th>
    </tr>
    <tr>
        <td rowspan="2">Aluno</td>
        <td>Nome: Ana</td>
    </tr>
    <tr>
        <td>Curso: ADS</td>
    </tr>
</table>

colspan="2" faz a célula ocupar duas colunas. rowspan="2" faz a célula ocupar duas linhas. Em páginas atuais, a aparência das bordas e demais estilos deve ser definida preferencialmente com CSS.

7. Formulários

Formulários permitem coletar informações fornecidas pelo usuário. O elemento <form> envolve campos de texto, caixas de seleção, botões de opção, listas, botões de envio e outros controles.

7.1 Form, action e method

<form action="/processar-cadastro" method="post">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome">

    <button type="submit">Enviar</button>
</form>
  • action: define o destino que processará os dados quando o formulário for enviado.
  • method: define o método HTTP utilizado para enviar os dados, normalmente GET ou POST.
  • name: identifica o campo no conjunto de dados enviado. Um campo sem name normalmente não é enviado.
MétodoComportamentoUso indicado
GETOs dados são enviados na URL e ficam visíveis no endereço.Consultas e dados não sensíveis, geralmente em pequenas quantidades.
POSTOs dados são enviados no corpo da requisição, não na URL.Envio de dados pessoais, formulários de cadastro e maiores quantidades de dados.

Importante: POST não criptografa os dados por si só. Para proteger informações durante a transmissão, é necessário utilizar HTTPS e implementar os controles de segurança adequados no servidor.

O atributo for do elemento <label> deve ter o mesmo valor do atributo id do campo correspondente. Isso associa a legenda ao controle e facilita sua utilização.

7.3 Seleção, agrupamento e botões

Radio button: permite escolher uma opção dentro de um grupo. Para que as opções sejam mutuamente exclusivas, elas devem compartilhar o mesmo atributo name.

<input type="radio" id="manha" name="periodo" value="manha">
<label for="manha">Manhã</label>

<input type="radio" id="noite" name="periodo" value="noite">
<label for="noite">Noite</label>

Checkbox: permite marcar nenhuma, uma ou várias opções.

<input type="checkbox" id="html" name="tecnologias" value="HTML">
<label for="html">HTML</label>

<input type="checkbox" id="css" name="tecnologias" value="CSS">
<label for="css">CSS</label>

Select, option e optgroup: criam uma lista suspensa de opções, que podem ser agrupadas por categorias.

<label for="curso">Curso:</label>
<select id="curso" name="curso">
    <option value="">Selecione</option>
    <optgroup label="Tecnologia">
        <option value="ads" selected>Análise e Desenvolvimento de Sistemas</option>
        <option value="si">Sistemas de Informação</option>
    </optgroup>
</select>

O atributo selected indica a opção inicialmente selecionada. O atributo value define o valor enviado.

Datalist: oferece sugestões predefinidas para um campo de entrada. O atributo list do input referencia o id do datalist.

<label for="cidade">Cidade:</label>
<input list="cidades" id="cidade" name="cidade">
<datalist id="cidades">
    <option value="Presidente Prudente">
    <option value="São Paulo">
    <option value="Campinas">
</datalist>

Fieldset e legend: agrupam campos relacionados dentro de um formulário e fornecem um título para o grupo.

<fieldset>
    <legend>Dados pessoais</legend>
    <label for="nome2">Nome:</label>
    <input type="text" id="nome2" name="nome">
</fieldset>

Botões:

  • submit: envia o formulário para o destino definido em action.
  • reset: restaura os campos aos valores iniciais.
  • button: botão genérico, normalmente utilizado com JavaScript.
<input type="submit" value="Enviar">
<input type="reset" value="Limpar">
<input type="button" value="Ação personalizada">

8. Elementos semânticos

Elementos semânticos descrevem o papel das regiões da página. Um documento pode ser compreendido como uma árvore de regiões, facilitando a leitura do código, a manutenção e a navegação por tecnologias assistivas.

<body>
    <header>
        <h1>Nome do site</h1>
    </header>

    <nav>
        <a href="index.html">Início</a>
        <a href="projetos.html">Projetos</a>
    </nav>

    <main>
        <section>
            <h2>Conteúdo principal</h2>
            <article>
                <h3>Notícia ou publicação</h3>
                <p>Texto do conteúdo.</p>
            </article>
        </section>
        <aside>Conteúdo complementar</aside>
    </main>

    <footer>Informações de rodapé</footer>
</body>
ElementoSignificado / utilização
<header>Cabeçalho de uma página ou de uma região.
<nav>Região de navegação e menus de links.
<main>Conteúdo principal da página.
<section>Agrupa conteúdo relacionado, normalmente com um título.
<article>Conteúdo independente, como notícia, artigo ou publicação.
<aside>Conteúdo complementar ou relacionado ao conteúdo principal.
<footer>Rodapé de uma página ou região.

Os elementos semânticos indicam a função do conteúdo, mas não determinam automaticamente sua aparência visual. Sem CSS, eles não se transformam necessariamente em colunas, menus horizontais ou caixas coloridas.

9. Boas práticas e revisão

  • Utilize lang="pt-BR" quando o conteúdo estiver em português do Brasil.
  • Prefira tags em letras minúsculas e mantenha a indentação consistente.
  • Organize os títulos hierarquicamente, sem escolher níveis apenas pelo tamanho visual.
  • Associe cada campo de formulário a um label.
  • Forneça texto alternativo adequado em imagens informativas.
  • Utilize tabelas para dados tabulares, não para organizar o layout da página.
  • Use elementos semânticos quando eles representarem corretamente a função da região.
  • Verifique os caminhos de imagens, páginas e demais arquivos do projeto.

Exemplo integrador: página de inscrição

O exemplo abaixo reúne estrutura semântica, títulos, parágrafos, links, listas, tabela e formulário.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Inscrição em oficina</title>
</head>
<body>
    <header><h1>Oficinas de Tecnologia</h1></header>
    <nav><a href="#inscricao">Inscreva-se</a></nav>
    <main>
        <section>
            <h2>Oficinas disponíveis</h2>
            <ul>
                <li>Introdução ao HTML</li>
                <li>Criação de páginas Web</li>
            </ul>
        </section>
        <section id="inscricao">
            <h2>Formulário de inscrição</h2>
            <form action="/inscricao" method="post">
                <label for="nome-inscrito">Nome:</label>
                <input id="nome-inscrito" name="nome"
                       type="text" required>
                <label for="email-inscrito">E-mail:</label>
                <input id="email-inscrito" name="email"
                       type="email" required>

            </form>
        </section>
    </main>
    <footer>Mostra de Tecnologia</footer>
</body>
</html>

O atributo action do exemplo é ilustrativo: para que o cadastro seja efetivamente processado, é necessário existir uma aplicação no servidor preparada para receber e tratar os dados.

10. CSS: especificidade

A especificidade é o critério utilizado pelo navegador para decidir qual declaração CSS será aplicada quando duas ou mais regras atingem o mesmo elemento e definem a mesma propriedade. Em geral, o seletor com maior especificidade prevalece.

Por exemplo, se uma regra define todos os parágrafos como vermelhos e outra define uma classe como verde, um parágrafo que possua essa classe ficará verde, pois o seletor de classe tem maior especificidade que o seletor de elemento.

/* Seletor de elemento */
p {
    color: red;
}

/* Seletor de classe: prevalece sobre p */
.destaque {
    color: green;
}

/* Seletor de ID: prevalece sobre os anteriores */
#aviso {
    color: blue;
}

10.1 Hierarquia e cálculo

Para compreender a especificidade, podemos organizar os seletores em uma hierarquia. A pontuação didática apresentada nos materiais ajuda a comparar regras:

Tipo de seletorExemploPontuação didática

ID#navbar100 por ID
Classe, pseudoclasse e atributo.menu, :hover, [href]10 por ocorrência
Elemento e pseudoelementop, h1, ::before1 por ocorrência
Seletor universal*0

Some os valores de cada categoria para comparar seletores. Exemplos:

SeletorCálculoResultado
p1 elemento1
.intro1 classe10
p.intro1 elemento + 1 classe11

O cálculo é uma simplificação para fins de aprendizagem: na comparação real, o navegador considera separadamente as categorias de especificidade, em vez de tratar os números como uma pontuação decimal comum. Um seletor com mais IDs, por exemplo, prevalece sobre qualquer quantidade de classes ou elementos.

Quando duas regras têm a mesma especificidade e importância, a declaração que aparece por último na folha de estilos prevalece. A herança e o seletor universal não aumentam a especificidade.

10.2 Regra !important

A declaração !important atribui prioridade especial a uma declaração CSS e pode fazer com que ela prevaleça sobre declarações normais, mesmo que estas venham de seletores mais específicos.

p {
    color: red !important;
}

#aviso {
    color: blue;
}

No exemplo, o parágrafo com ID aviso continua vermelho, pois a declaração vermelha foi marcada como importante. Evite utilizar !important sem necessidade: seu uso excessivo dificulta a manutenção e a sobrescrita dos estilos. A cascata também considera origem, camada, importância e contexto; portanto, não é correto afirmar que !important sempre vence absolutamente qualquer regra em todos os cenários.

11. Box Model e Flexbox

O layout é a organização visual dos elementos em uma página. O HTML define a estrutura do conteúdo e o CSS controla sua aparência, dimensões, espaçamentos e posicionamento. Para construir layouts, é importante entender o Box Model e o Flexbox.

11.1 As quatro partes do Box Model

No modelo de caixas do CSS, cada elemento é representado por uma caixa composta por quatro partes:

  • Content (conteúdo): área em que ficam o texto, a imagem ou outros elementos.
  • Padding (preenchimento): espaço interno entre o conteúdo e a borda.
  • Border (borda): contorno ao redor do conteúdo e do padding.
  • Margin (margem): espaço externo que separa a caixa dos demais elementos.
.caixa {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}

No modelo padrão (content-box), a largura total da caixa acima, sem considerar as margens, será: 300 px de conteúdo + 40 px de padding horizontal + 10 px de bordas = 350 px. As margens acrescentam mais 20 px ao espaço ocupado horizontalmente.

Para tornar o cálculo das dimensões mais previsível, é comum utilizar box-sizing: border-box. Nesse modelo, a largura declarada já inclui conteúdo, padding e bordas.

* {
    box-sizing: border-box;
}

.caixa {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

Com border-box, a caixa permanece com 300 px de largura total, incluindo padding e bordas. A margem continua sendo espaço externo e não está incluída nessa largura.

As propriedades margin e padding aceitam atalhos:

DeclaraçãoInterpretação
padding: 10px;10 px em todos os lados.
padding: 10px 20px;10 px em cima e embaixo; 20 px nas laterais.
padding: 10px 20px 30px;10 px em cima; 20 px nas laterais; 30 px embaixo.
padding: 10px 20px 30px 40px;Topo, direita, base e esquerda, nessa ordem.

A mesma lógica de atalhos se aplica à propriedade margin.

11.2 Flexbox e seus eixos

Flexbox é um modelo de layout CSS que facilita a organização, o alinhamento e a distribuição de espaço entre elementos. Para ativá-lo, define-se display: flex no elemento pai, que passa a ser o flex container. Seus filhos diretos tornam-se flex items.

.container {
    display: flex;
}

O Flexbox trabalha com dois eixos:

  • Eixo principal (main axis): direção em que os itens são organizados. Por padrão, é horizontal.
  • Eixo transversal (cross axis): eixo perpendicular ao principal.

Por padrão, flex-direction: row organiza os itens em linha. Se for utilizado column, os itens serão organizados em coluna. A propriedade justify-content atua no eixo principal, enquanto align-items atua no eixo transversal.

11.3 Propriedades do Flexbox

PropriedadeFunção e valores comuns
flex-directionDefine a direção: row, row-reverse, column ou column-reverse.
flex-wrapControla a quebra de linha: nowrap (padrão), wrap ou wrap-reverse.
flex-flowAtalho que combina flex-direction e flex-wrap.
justify-contentDistribui os itens no eixo principal: flex-start, flex-end, center, space-between, space-around e space-evenly.
align-itemsAlinha os itens no eixo transversal: stretch, center, flex-start, flex-end e baseline.
align-contentDistribui o conjunto de linhas no eixo transversal. É relevante quando há múltiplas linhas e espaço disponível.
align-selfPermite alinhar individualmente um item, sobrescrevendo o alinhamento geral definido por align-items.
gapDefine o espaço entre os itens sem precisar aplicar margens individualmente.

Exemplo de um conjunto de cards responsivos:

.cards {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: space-between;
    align-items: stretch;
    gap: 20px;
}

.card {
    flex: 1 1 220px;
}

Nesse exemplo, os cards ficam lado a lado enquanto houver espaço e passam para novas linhas quando necessário. A propriedade gap controla a distância entre eles. Também é possível separar os espaços horizontal e vertical usando column-gap e row-gap.

Atenção: align-content atua sobre as linhas como um conjunto, enquanto align-items alinha os itens dentro de cada linha. align-self altera o alinhamento de um item específico.

12. Pseudoclasses em CSS

As pseudoclasses selecionam elementos HTML de acordo com um estado, uma interação ou uma posição na estrutura do documento. Sua sintaxe utiliza dois-pontos (:) e não exige que a pseudoclasse seja adicionada ao atributo class do HTML.

seletor:pseudoclasse {
    propriedade: valor;
}

12.1 Estados de interação

PseudoclasseQuando é aplicada
:hoverQuando o ponteiro está sobre o elemento.
:activeDurante a ativação do elemento, por exemplo, enquanto o botão do mouse está pressionado.
:focusQuando o elemento recebe foco, por exemplo, ao clicar em um campo ou navegar até ele com a tecla Tab.
:focus-visibleAplica estilo de foco quando o navegador entende que o indicador visual é especialmente necessário, como na navegação por teclado.

:visitedSeleciona links já visitados.
 
button {
    background-color: blue;
    color: white;
}

button:hover {
    background-color: green;
}

button:active {
    background-color: red;
    transform: scale(0.98);
}

input:focus {
    border: 2px solid blue;
    background-color: #e0f2fe;
}

a:link { color: blue; }
a:visited { color: purple; }
a:hover { color: green; }
a:active { color: red; }

A pseudoclasse :active representa um estado momentâneo durante a ativação; não significa que o elemento permanecerá selecionado depois do clique. Preserve sempre um indicador de foco visível para facilitar a navegação por teclado.

12.2 Pseudoclasses posicionais

As pseudoclasses posicionais selecionam elementos conforme sua posição entre os filhos de um mesmo elemento pai.

li:first-child {
    color: red;
}

    color: blue;

}

Diferença importante: :nth-child() considera a posição entre todos os filhos do mesmo pai. Já :nth-of-type() considera a posição entre os irmãos que possuem o mesmo tipo de elemento. Se houver um parágrafo antes de uma lista, por exemplo, o primeiro li poderá ser o segundo filho.

}

    font-size: 30px;
}

13. Media Queries e responsividade

Até aqui, o CSS foi usado para definir uma aparência única para a página. No entanto, um mesmo site pode ser aberto em celulares, tablets e computadores, que possuem larguras de visualização diferentes. A pergunta que orienta esta seção é: "o título deve ter sempre o mesmo tamanho?" A resposta é não — e as Media Queries são o recurso do CSS que permite adaptar a apresentação conforme o tamanho da tela.

Design responsivo é a criação de páginas que continuam legíveis e confortáveis de utilizar em diferentes tamanhos de tela. A mesma página HTML pode apresentar aparências diferentes, sem duplicar o conteúdo.

13.1 Por que o design responsivo importa

Os slides da Aula 14 destacam três preocupações centrais do design responsivo:

Preocupação O que significa Exemplo prático
Texto legível Em telas menores, um título muito grande pode ocupar espaço demais. Reduzir o font-size do h1 em telas estreitas.
Elementos adequados Uma caixa pode ocupar mais largura no celular e ter menos espaço. Passar uma caixa de width: 70% para width: 95%.
Menu acessível Links podem passar de uma linha horizontal para uma lista vertical. Mudar display: inline-block para display: block.

A ideia central é que a mesma página HTML pode apresentar aparências diferentes. O HTML organiza o conteúdo; o CSS define a aparência; as Media Queries escolhem quando aplicar determinados estilos.

13.2 Sintaxe e condições

Uma Media Query é uma condição escrita no CSS. Ela diz: "se acontecer isto, use estes estilos". A sintaxe básica utiliza @media seguida de uma condição entre parênteses e de um bloco de declarações:

@media (max-width: 600px) {
    h1 {
        font-size: 24px;
    }
}

Nesse exemplo:

  • A condição é: a largura da tela é de 600 px ou menos.
  • A mudança é: o título passa a ter 24 px de tamanho.
  • Quando a condição não é atendida, continuam valendo os estilos gerais definidos fora do bloco @media.

Os dois operadores principais são:

Operador Quando aplica Exemplo
max-width Aplica as regras até uma largura máxima. O limite está incluído. max-width: 600px vale em telas de 600 px ou menos.
min-width Aplica as regras a partir de uma largura mínima. O limite está incluído. min-width: 800px vale em telas de 800 px ou mais.

Atenção: a Media Query não significa "celular". Ela verifica uma largura. Uma tela de 400 px aplica a regra de max-width: 600px; uma tela de 900 px não aplica. O ponto de quebra (breakpoint) deve ser escolhido conforme o conteúdo e o comportamento do layout, e não apenas por um modelo fixo de aparelho.

13.3 A meta viewport: configuração essencial no HTML

Antes de escrever as Media Queries, é necessário configurar o viewport no <head> do HTML. Essa linha orienta o navegador do celular a usar a largura real da tela do dispositivo como referência, em vez de simular uma tela maior:

<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • width=device-width — informa que a largura deve ser a do dispositivo.
  • initial-scale=1.0 — define o nível de zoom inicial.

Sem essa configuração, as Media Queries podem não funcionar como esperado em dispositivos móveis. Além disso, o HTML deve conectar-se ao arquivo CSS por meio do elemento <link>:

<link rel="stylesheet" href="estilos.css">

O HTML continua responsável pela estrutura; o CSS controla cores, fontes, tamanhos, espaçamentos e apresentação; e as Media Queries adaptam esses estilos conforme as condições da tela.

13.4 Exemplos práticos de Media Queries

Exemplo 1 — alterar cores e tamanho do título

body {
    background-color: #fef3c7;
}

h1 {
    font-size: 36px;
}

@media (max-width: 600px) {
    body {
        background-color: #dbeafe;
    }

    h1 {
        font-size: 24px;
    }
}

Em telas maiores que 600 px, o fundo permanece amarelo-claro e o título tem 36 px. Em telas de até 600 px, o fundo passa a azul-claro e o título é reduzido para 24 px.

Exemplo 2 — adaptar largura e espaçamento de uma caixa

.caixa {
    width: 70%;
    padding: 40px;
    background-color: #bbf7d0;
}

@media (max-width: 650px) {
    .caixa {
        width: 95%;
        padding: 15px;
        background-color: #fde68a;
    }
}

Em telas maiores, a caixa ocupa 70% da largura com bastante espaçamento interno. Em telas de até 650 px, ocupa 95% e o padding diminui, deixando mais espaço para o conteúdo.

Exemplo 3 — transformar um menu horizontal em vertical

nav a {
    display: inline-block;
    padding: 10px 20px;
    background-color: #2563eb;
    color: white;
}

@media (max-width: 600px) {
    nav a {
        display: block;
    }
}

Nesse exemplo, não é necessário alterar o HTML: os links ficam lado a lado em telas maiores e passam a ocupar linhas separadas em telas pequenas.

Exemplo 4 — juntando HTML e CSS completos

Os slides apresentam um exemplo mínimo que reúne HTML e CSS. O HTML cria o título e o parágrafo:

<h1>Olá, turma!</h1>
<p>Meu primeiro site.</p>

O CSS define a aparência geral e, depois, a adaptação para telas menores:

h1 {
    color: blue;
    font-size: 36px;
}

@media (max-width: 600px) {
    h1 {
        font-size: 24px;
    }
}

Em telas maiores que 600 px, o título fica azul e com 36 px. Em telas de até 600 px, o título é reduzido para 24 px. A cor permanece azul, pois não foi alterada dentro da Media Query.

13.5 Como testar as Media Queries

Para verificar o funcionamento das Media Queries:

  1. Abra a página no Chrome ou Edge.
  2. Pressione F12 para abrir as ferramentas do desenvolvedor.
  3. Utilize a visualização de dispositivos móveis (Ctrl + Shift + M).
  4. Teste diferentes larguras, como 400 px, 600 px e 900 px.

No limite exato definido por max-width (por exemplo, 600 px), a regra também é aplicada, pois o limite está incluído.

13.6 Erros comuns

  • Esquecer o caractere @ antes de media.
  • Não fechar corretamente as chaves do bloco @media.
  • Esquecer de salvar o arquivo CSS.
  • Não conferir se o HTML está conectado ao arquivo CSS correto.
  • Esquecer a meta viewport no <head>.

13.7 Desafio de revisão — Biblioteca da Escola

Considere uma página com cabeçalho, título, menu de navegação e uma caixa de aviso. Crie uma Media Query para telas de até 600 px e faça as seguintes alterações:

  1. Mude o fundo da página para azul-claro.
  2. Reduza o título para 24 px.
  3. Coloque cada link do menu em uma linha separada.
  4. Reduza o padding da caixa de aviso para 15 px.

O desafio pode ser resolvido apenas com CSS, sem modificar a estrutura HTML.

@media (max-width: 600px) {
    body {
        background-color: #dbeafe;
    }

    h1 {
        font-size: 24px;
    }

    nav a {
        display: block;
    }

    .aviso {
        padding: 15px;
    }
}

14. Media Queries + Flexbox: reorganizando o layout

As Media Queries sozinhas alteram estilos, mas muitas vezes o que se deseja é reorganizar os elementos na página. Para isso, o Flexbox é o parceiro natural das Media Queries. Enquanto o Flexbox organiza os elementos em linha ou coluna, a Media Query escolhe quando mudar essa organização.

14.1 Cada recurso tem um papel

Recurso Papel
HTML Cria a estrutura: caixas, títulos e links.
CSS Define cores, espaços e aparência.
Flexbox Organiza elementos em linha ou coluna.
Media Query Escolhe quando mudar as regras de CSS.

14.2 O problema: a tela muda de tamanho

Queremos o mesmo HTML, mas com uma organização melhor no celular. No computador, os elementos ficam em linha; no celular, devem ficar empilhados.

Tela Organização desejada
Maior Três caixas lado a lado (HTML, CSS, WEB).
Menor (≤ 600 px) As mesmas caixas empilhadas verticalmente.

A solução combina três passos: ativar o Flexbox, definir o espaçamento e, dentro de uma Media Query, trocar a direção de linha para coluna.

14.3 Passo 1 — display: flex

A propriedade display: flex organiza os elementos na mesma linha por padrão. Ela é aplicada ao elemento pai, que se torna um flex container; seus filhos diretos tornam-se flex items.

.caixas {
    display: flex;
}

Sem Media Query, as três caixas ficam lado a lado. Esse é o comportamento padrão do Flexbox.

14.4 Passo 2 — gap

A propriedade gap acrescenta espaço entre os elementos do Flexbox, sem precisar aplicar margens individuais a cada item.

.caixas {
    display: flex;
    gap: 10px;
}

Nesse exemplo, gap: 10px significa 10 pixels de separação entre as caixas. Também é possível separar os espaços horizontal e vertical usando column-gap e row-gap.

14.5 Passo 3 — flex-direction

A propriedade flex-direction é a que vamos mudar no celular. Ela define a direção do eixo principal:

Valor Comportamento
row Itens em linha (padrão).
row-reverse Itens em linha, na ordem inversa.
column Itens em coluna (empilhados).
column-reverse Itens em coluna, na ordem inversa. 
/* Linha */
flex-direction: row;

/* Coluna */
flex-direction: column;

14.6 Juntando Flexbox e Media Query

Agora vamos juntar os dois recursos. O Flexbox organiza; a Media Query altera a direção quando a tela diminui.

.caixas {
    display: flex;
    gap: 10px;
}

@media (max-width: 600px) {
    .caixas {
        flex-direction: column;
    }
}

Funcionamento:

  • Acima de 600 px, o display: flex mantém as caixas em linha (padrão row).
  • Até 600 px, a Media Query aplica flex-direction: column, empilhando as caixas.
  • O gap: 10px continua valendo nos dois casos, agora como espaço vertical entre as caixas empilhadas.

14.7 Exemplo 1 — três caixas

Objetivo: mudar de linha para coluna.

HTML

Apenas uma div para agrupar e três divs para as caixas:

<h1>Exemplo 1: três caixas</h1>

<div class="caixas">
    <div class="caixa">Caixa 1</div>
    <div class="caixa">Caixa 2</div>
    <div class="caixa">Caixa 3</div>
</div>

Observação: caixas é a classe do grupo; caixa é a classe de cada item. Essa distinção é importante: o display: flex é aplicado ao grupo, não aos itens individuais.

CSS

.caixas {
    display: flex;
    gap: 10px;
}

.caixa {
    flex: 1;
    padding: 20px;
    background-color: #dbeafe;
    border: 1px solid #93c5fd;
    text-align: center;
}

@media (max-width: 600px) {
    .caixas {
        flex-direction: column;
    }
}

Resultado:

  • Tela maior: três caixas lado a lado, com espaçamento entre elas.
  • Tela menor (≤ 600 px): três caixas empilhadas verticalmente.

14.8 Exemplo 2 — menu e cartões de cursos

Os slides propõem montar uma página simples com menu e cursos. O mesmo HTML pode ser reorganizado com Flexbox e Media Query.

HTML

<nav class="menu">
    <a href="#">Início</a>
    <a href="#">Cursos</a>
    <a href="#">Contato</a>
</nav>

<section class="cards">
    <article class="card">HTML</article>
    <article class="card">CSS</article>
    <article class="card">WEB</article>
</section>

CSS

/* Menu horizontal em telas maiores */
.menu {
    display: flex;
    gap: 20px;
    background-color: #1e3a8a;
    padding: 15px;
}

.menu a {
    color: white;
    text-decoration: none;
}

/* Cartões lado a lado em telas maiores */
.cards {
    display: flex;
    gap: 20px;
    padding: 20px;
}

.card {
    flex: 1 1 220px;
    padding: 40px;
    background-color: #dbeafe;
    text-align: center;
    border-radius: 8px;
}

/* Em telas pequenas: menu e cartões em coluna */
@media (max-width: 600px) {
    .menu {
        flex-direction: column;
        gap: 10px;
    }

    .cards {
        flex-direction: column;
    }
}

Funcionamento:

  • Em telas maiores, o menu fica horizontal e os cartões ficam lado a lado.
  • Em telas de até 600 px, o menu passa a ser uma lista vertical e os cartões são empilhados.
  • O HTML permanece exatamente o mesmo nos dois casos.

14.9 Propriedades do Flexbox úteis em layouts responsivos

Além de display, gap e flex-direction, outras propriedades do Flexbox ajudam a construir layouts que se adaptam bem:

Propriedade Função e valores comuns
flex-wrap Controla a quebra de linha: nowrap (padrão), wrap ou wrap-reverse.
justify-content Distribui os itens no eixo principal: flex-start, flex-end, center, space-between, space-around e space-evenly.
align-items Alinha os itens no eixo transversal: stretch, center, flex-start, flex-end e baseline.
align-content Distribui o conjunto de linhas no eixo transversal. É relevante quando há múltiplas linhas e espaço disponível.
align-self Permite alinhar individualmente um item, sobrescrevendo o align-items do container.

Um exemplo de cartões responsivos que quebram linha automaticamente:

    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: space-between;
    align-items: stretch;
    gap: 20px;
}

    flex: 1 1 220px;
}

Nesse exemplo, os cartões ficam lado a lado enquanto houver espaço e passam para novas linhas quando necessário. A propriedade gap controla a distância entre eles.

14.10 Boas práticas ao combinar Flexbox e Media Queries

  • Prefira reorganizar a empilhar: em telas pequenas, muitas vezes o melhor é empilhar os elementos em coluna, mantendo a legibilidade.
  • Não duplique o HTML: a mesma estrutura deve servir para todas as telas; a adaptação fica no CSS.
  • Escolha breakpoints pelo conteúdo: não escolha 600 px apenas porque é um número redondo; teste o layout e identifique onde ele começa a ficar desconfortável.
  • Use gap em vez de margens individuais: o espaçamento fica mais previsível e fácil de manter.
  • Combine com a meta viewport: sem ela, as Media Queries podem não funcionar corretamente em dispositivos móveis.
  • Teste as larguras de transição: verifique o comportamento exatamente no ponto de quebra (por exemplo, 600 px) para garantir que não haja saltos inesperados.

15. JavaScript: introdução e DOM

O JavaScript é a linguagem de programação da web. Enquanto o HTML estrutura o conteúdo e o CSS define a apresentação, o JavaScript acrescenta comportamento: calcula, valida dados, manipula o conteúdo, altera atributos, oculta e exibe elementos, e reage às ações do usuário.

O JavaScript não substitui o HTML. As três tecnologias se complementam:

Tecnologia Papel Pergunta que responde
HTML Estrutura O que existe na página?
CSS Apresentação Como a página aparece?
JavaScript Comportamento O que acontece?

15.1 Onde colocar JavaScript no HTML

O JavaScript pode ser incluído em um documento HTML de duas maneiras:

  • Código interno: escrito diretamente dentro da tag <script>, que pode ser inserida no <head> ou no <body>.
  • Código externo: escrito em um arquivo com extensão .js e vinculado ao HTML por meio da tag <script src="arquivo.js"></script>.

Um documento HTML pode conter várias tags <script>, permitindo utilizar diferentes códigos ou arquivos JavaScript.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Exemplo</title>
</head>
<body>
    <h1>Aprendendo JavaScript</h1>
    <script>
        alert("Olá!");
    </script>
</body>
</html>

Importante: a tag <script> é HTML; o conteúdo entre ela e </script> é JavaScript.

JavaScript em arquivo externo (.js)

Quando o código é extenso ou precisa ser reutilizado, recomenda-se separá-lo em um arquivo .js:

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <script src="exemplo2.js" defer></script>
    <title>Exemplo</title>
</head>
<body>
    <h1>Aprendendo JavaScript</h1>
</body>

Arquivo exemplo2.js (sem tags <script>):

alert("Olá!");
  • src indica o arquivo JavaScript a carregar.
  • O arquivo .js deve estar na mesma pasta do HTML ou o caminho deve ser ajustado.
  • O atributo defer adia a execução do script até que o HTML tenha sido analisado.

Duas posições possíveis

O mesmo arquivo .js pode ser chamado no fim do <body> ou no <head> com defer:

<!-- Opção A: fim do body -->
<body>
    <h1>Olá, turma!</h1>
    <script src="exemplo2.js"></script>
</body>

<!-- Opção B: head com defer -->
<head>
    <script src="exemplo2.js" defer></script>
</head>

Em ambas as opções, o arquivo exemplo2.js é o mesmo. A posição da tag e o uso de defer mudam apenas o momento da execução. As duas formas são corretas e utilizadas atualmente.

15.2 Primeiros comandos: alert() e console.log()

alert()

O comando alert() abre uma janela de aviso no navegador com a mensagem especificada.

<h1>Olá, turma!</h1>
<script>
    alert("Bem-vindos ao JavaScript!");
</script>
  • alert abre uma janela de aviso.
  • O texto deve estar entre aspas.
  • Os parênteses contêm a mensagem.
  • O aviso aparece ao carregar a página.

console.log()

O comando console.log() escreve uma informação no Console do navegador, sem inserir a mensagem na página HTML. Para visualizá-la, pressione F12 e acesse a guia Console.

<script>

</script>

Esse recurso também ajuda a investigar problemas e acompanhar o fluxo de execução do código.

Anatomia de um comando

Elemento Função

Parênteses ( ) Informam o valor que será usado pelo comando, como um texto.
Aspas " " Delimitam o texto que queremos apresentar.
Ponto e vírgula ; Marca o fim de uma instrução; é uma convenção recomendada nos exemplos.

16. O DOM: Document Object Model

O DOM (Document Object Model ou Modelo de Objeto de Documentos) é uma representação em objetos da estrutura da página. Ele permite que programas, como scripts JavaScript, acessem e modifiquem partes do documento.

O navegador interpreta o HTML e disponibiliza a estrutura DOM enquanto processa a página. Cada parte do documento é um nó na árvore DOM.

16.1 Do HTML à árvore DOM

Considere o HTML a seguir:

<html>
<body>
    <h1>Minha página</h1>
    <p>Bem-vindo!</p>
    <button>Clique aqui</button>
</body>
</html>

A árvore DOM simplificada fica assim:

document
└── html
    └── body
        ├── h1
        ├── p
        └── button

O elemento body é pai dos elementos h1, p e button.

16.2 Tipos de nós

Nó Descrição
Documento Proprietário de todos os nós no documento.
<html> Nó de elemento.
<head> Nó de elemento.
<body> Nó de elemento.
<a> Nó de elemento.
href Nó de atributo.
<h1> Nó de elemento.
Meu cabeçalho Nó de texto.

16.3 HTML e DOM não são idênticos

Aspecto HTML DOM
Natureza Código-fonte escrito no editor. Estrutura atual disponível no navegador.
Alteração Não é modificado por scripts. Pode ser alterado por scripts.
Resultado Define a estrutura inicial. Reflete o que o navegador apresenta, considerando HTML, CSS e alterações feitas.

16.4 Encontrando elementos

Para manipular elementos HTML com JavaScript, primeiro é necessário encontrá-los. Existem várias maneiras:

  • Por ID (getElementById).
  • Pelo nome da tag.
  • Pela classe (class name).
  • Por seletores CSS.

getElementById()

O atributo id funciona como um identificador único no documento HTML.

<h1 id="titulo">Meu site</h1>

No CSS, #titulo seleciona o elemento. No JavaScript, getElementById("titulo") localiza o mesmo elemento.

<h1 id="titulo">Aprendendo DOM</h1>
<script>
    console.log(document.getElementById("titulo"));
</script>

Leitura passo a passo:

  • document — documento HTML em uso.
  • getElementById — método que procura pelo ID.
  • "titulo" — valor do atributo id procurado.

Cuidado: use getElementById com a capitalização exata e não coloque # dentro das aspas.

Alterando conteúdo com textContent

<p id="mensagem">Mensagem original.</p>
<script>
    const paragrafo = document.getElementById("mensagem");
    paragrafo.textContent = "O texto foi alterado pelo JavaScript!";
    console.log(document.getElementById("mensagem"));
</script>

Dois elementos, dois identificadores

<h1 id="titulo">Título</h1>
<p id="aviso">Mensagem</p>
<script>
    console.log(document.getElementById("titulo"));
    console.log(document.getElementById("aviso"));
</script>

O Console mostra a referência a cada elemento localizado.

17. Alterando estilos com JavaScript

O DOM permite localizar um elemento e modificar sua aparência com JavaScript. Hoje vamos alterar a aparência do elemento, e não necessariamente seu texto.

Tecnologia Para que serve Exemplo
HTML Cria um parágrafo <p id="aviso">Olá</p>
CSS Define estilo inicial p { color: gray; }
JavaScript Modifica o estilo durante o uso elemento.style.color = "blue"

Modificar o estilo pelo DOM não reescreve o arquivo HTML salvo no computador.

17.1 Sintaxe: selecionar → acessar style → atribuir

const aviso = document.getElementById("aviso");
aviso.style.color = "#155e75";
  • document representa a página HTML atual.
  • getElementById("aviso") encontra o elemento pelo ID.
  • style acessa suas propriedades de apresentação.
  • color = "blue" define a cor do texto.

17.2 Atenção aos nomes das propriedades CSS

Em JavaScript, propriedades CSS compostas usam camelCase (sem hífen).

No CSS No JavaScript Resultado
color style.color Cor do texto
background-color style.backgroundColor Cor de fundo
font-size style.fontSize Tamanho da fonte
border-color style.borderColor Cor da borda

Os valores devem estar entre aspas; medidas como tamanho da fonte exigem unidade: "24px".

17.3 Exemplo 01 — aviso de inscrições

<p id="aviso">Inscrições abertas para o curso!</p>
<script>
    const aviso = document.getElementById("aviso");
    aviso.style.color = "#155e75";
    aviso.style.backgroundColor = "#cffafe";
    aviso.style.fontSize = "24px";
</script>

Resultado esperado: mensagem azul-petróleo, fundo azul-claro e fonte maior. O texto e a estrutura permanecem os mesmos.

17.4 Exemplo 02 — destacar prazo de matrícula

<p id="mensagem">Prazo de matrícula: sexta-feira.</p>
<button onclick="destacar()">Destacar</button>
<script>
    function destacar() {
        const msg = document.getElementById("mensagem");
        msg.style.backgroundColor = "#ffedd5";
        msg.style.color = "#9a3412";
        msg.style.padding = "12px";
        msg.style.border = "2px solid #f97316";
    }
</script>
  • onclick indica o que fazer quando o botão é clicado.
  • destacar() é uma função com as instruções.
  • Ao clicar, o navegador executa a função.
  • O JavaScript altera a aparência do parágrafo.

17.5 Exemplo — mudar o status de uma tarefa

<p id="status">Atividade: pendente</p>
<button onclick="concluir()">Concluir tarefa</button>
<script>
    function concluir() {
        const status = document.getElementById("status");
        status.textContent = "Atividade: concluída";
        status.style.color = "#166534";
        status.style.fontWeight = "bold";
    }
</script>

Resultado: PENDENTE → CONCLUÍDA, com cor verde e negrito.

17.6 O que é uma função?

Uma função reúne instruções com um nome; elas são executadas quando a função é chamada.

  • function destacar() { ... } define o conjunto de instruções.
  • onclick="destacar()" chama a função quando ocorre o clique.
  • O navegador identifica o parágrafo e modifica suas propriedades de estilo.
  • Antes do clique, a aparência é a definida pelo HTML/CSS; depois, fica destacada.

17.7 Revisão: JavaScript em arquivo externo

Você já pode separar HTML e JavaScript usando um arquivo .js.

<!-- 11_js_externo.html (no head) -->
<script src="11_estilo.js" defer></script>

<!-- 11_js_externo.html (no body) -->
<p id="info">Esta mensagem será formatada pelo arquivo 11_estilo.js.</p>

Arquivo 11_estilo.js (sem tags <script>):

const info = document.getElementById("info");
info.style.color = "#1d4ed8";
  • src indica qual arquivo JavaScript será carregado.
  • defer adia a execução até o HTML ser analisado.
  • O arquivo .js deve estar no caminho informado.
  • Não se usam tags <script> dentro do arquivo .js.

18. Mostrar, ocultar e destacar conteúdos

A visibilidade pode ser controlada sem modificar o conteúdo original do HTML.

18.1 display e visibility não fazem a mesma coisa

Instrução O que acontece Espaço na página
style.display = "none" O elemento não é exibido. Deixa de ocupar espaço.
style.display = "block" O elemento é exibido como bloco. Ocupa espaço novamente.
style.visibility = "hidden" O elemento fica invisível. O espaço é preservado.
style.visibility = "visible" O elemento volta a aparecer. O espaço permanece.

Use display = "block" quando for adequado ao elemento; outras exibições possíveis incluem inline e flex.

18.2 Exemplo 03 — documentos necessários

<p id="documentos" style="display: none">RG, CPF e comprovante de escolaridade.</p>
<button onclick="mostrar()">Mostrar</button>
<button onclick="ocultar()">Ocultar</button>

<script>
    function mostrar() {
        document.getElementById("documentos").style.display = "block";
    }
    function ocultar() {
        document.getElementById("documentos").style.display = "none";
    }
</script>
  • Ambas as funções selecionam o mesmo elemento.
  • mostrar() utiliza display = "block".
  • ocultar() utiliza display = "none".
  • O conteúdo continua no HTML, mas sua exibição muda.

18.3 Alternativa: criar uma classe CSS com classList

O CSS pode concentrar a aparência, enquanto o JavaScript decide quando aplicá-la.

/* CSS */
.destaque {
    color: #9a3412;
    background-color: #ffedd5;
    border: 2px solid #f97316;
    padding: 12px;
}

/* JavaScript */
const elemento = document.getElementById("mensagem");
elemento.classList.toggle("destaque");

classList.toggle("destaque") adiciona a classe se ela não existir e a remove em um próximo clique. Este é um aprofundamento opcional.

19. Validação de formulários

Formulários permitem coletar informações fornecidas pelo usuário. O JavaScript pode ser usado para validar esses dados antes do envio ao servidor.

19.1 Validação nativa do HTML

O HTML já oferece atributos de validação:

  • required — o campo precisa ser preenchido.
  • type="email" — valida o formato básico de e-mail.
  • min e max — definem valores mínimo e máximo para tipos numéricos.
  • maxlength — número máximo de caracteres.
  • pattern — expressão regular para validar o formato.
  • novalidate no <form> — desativa a validação automática do navegador.
<form action="/processar" method="post">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome" required>

    <label for="email">E-mail:</label>
    <input type="email" id="email" name="email" required>

    <button type="submit">Enviar</button>
</form>

19.2 Validação com JavaScript

Além da validação nativa, é possível criar validações personalizadas com JavaScript:

<form id="meuForm" action="/processar" method="post">
    <label for="idade">Idade:</label>
    <input type="number" id="idade" name="idade" required>
    <span id="erro-idade" style="color: red;"></span>
    <button type="submit">Enviar</button>
</form>

<script>
    const form = document.getElementById("meuForm");
    const idade = document.getElementById("idade");
    const erro = document.getElementById("erro-idade");

    form.addEventListener("submit", function(event) {
        const valor = Number(idade.value);
        if (valor < 16 || valor > 100) {
            event.preventDefault();
            erro.textContent = "A idade deve estar entre 16 e 100.";
            idade.style.borderColor = "red";
        } else {
            erro.textContent = "";
            idade.style.borderColor = "green";
        }
    });
</script>

19.3 Pseudoclasses de validação em CSS

O CSS também pode reagir ao estado de validação dos campos:

Pseudoclasse Aplicação
:required Campo marcado como obrigatório.
:valid Campo cujo valor atende às regras de validação.
:invalid Campo cujo valor não atende às regras de validação.
:disabled Controle desabilitado.
:checked Checkbox ou radio selecionado. 
input:invalid {
    border-color: red;
    background-color: #fee2e2;
}

input:valid {
    border-color: green;
    background-color: #dcfce7;
}

Importante: um campo obrigatório vazio pode ser considerado inválido. A validação do navegador auxilia o usuário, mas não substitui a validação dos dados no servidor.

O que acontece em 500 px e em 900 px?

  1. 500 px → linha; 900 px → coluna.
  2. 500 px → coluna; 900 px → linha.
  3. Ambos em coluna.
  4. Ambos em linha.
Ver resposta

Alternativa B. Em 500 px (≤ 600), a Media Query aplica column. Em 900 px (> 600), vale o estilo geral row.

Questão 20. Analise o código:

<div class="caixas">
  <div class="caixa">A</div>
  <div class="caixa">B</div>
</div>
.caixa { display: flex; }

Qual é o problema?

  1. Nenhum; as caixas ficam lado a lado.
  2. O display: flex foi aplicado aos itens, e não ao container; o correto seria .caixas { display: flex; }.
  3. div não aceita flex.
  4. O código quebra.
Ver resposta

Alternativa B. O Flexbox deve ser aplicado ao container (.caixas) para organizar os filhos. Aplicado ao item, ele apenas transforma cada caixa em um container flex individual, sem organizar a linha.

Questão 21. Analise o código:

.caixas {
  display: flex;
  gap: 20px;
}

Qual é a vantagem do gap em relação ao margin?

  1. gap só funciona em colunas.
  2. gap adiciona espaço apenas entre os itens, sem margens nas extremidades.
  3. gap substitui display: flex.
  4. gap só funciona com flex-wrap.
Ver resposta

Alternativa B. O gap distribui o espaço entre os itens de forma uniforme, sem criar margens externas que precisariam ser tratadas separadamente.

Questão 22. Analise o código:

nav a {
  display: inline-block;
  padding: 10px 20px;
}

@media (max-width: 600px) {
  nav a { display: block; }
}

Qual é o efeito em telas pequenas?

  2. Cada link ocupa uma linha separada, formando lista vertical.
  3. Os links desaparecem.
  4. Os links ficam sobrepostos.
Ver resposta

Alternativa B. display: block faz cada link ocupar toda a largura, empilhando-os verticalmente. É o padrão para menus responsivos.

Questão 23. Analise o código:

@media (max-width: 600px) { body { background: blue; } }
@media (min-width: 600px) { body { background: green; } }

Em uma tela de exatamente 600 px, o que acontece?

  1. Apenas azul.
  2. Apenas verde.
  3. Ambas as regras se aplicam; a última no arquivo prevalece.
  4. Nenhuma.
Ver resposta

Alternativa C. Tanto max-width: 600px quanto min-width: 600px incluem o limite, então ambas valem em 600 px. Como têm a mesma especificidade, a que vier por último vence. Recomenda-se usar max-width: 599px ou min-width: 601px para evitar sobreposição.

21.6 JavaScript: introdução e DOM

  <h1 id="titulo">Título</h1>

Alternativa B. O script é executado imediatamente ao ser encontrado, antes do <h1>. Soluções: mover o script para o fim do <body> ou usar defer.

Questão 25. Analise o código:

  4. O document é opcional.

Alternativa B. getElementById recebe apenas o valor do atributo id, sem o #. O # é usado em seletores CSS, não nesse método.

Questão 26. Analise o código:

21.7 O DOM: tipos de nós

Questão 27. Analise o código:

  2. Nó de atributo.
  3. Nó de texto.
  4. Nó de documento.
Ver resposta

Alternativa B. href é um nó de atributo. O <a> é nó de elemento; "Link" é nó de texto.

Questão 28. Qual afirmativa está correta?

  1. HTML e DOM são a mesma coisa.
  2. O HTML é o código-fonte; o DOM é a estrutura atual no navegador, que pode ser alterada por scripts.
  3. O DOM só existe no servidor.
  4. O HTML é alterado quando um script modifica o DOM.
Ver resposta

Alternativa B. O HTML é o arquivo salvo; o DOM é a representação viva no navegador. Alterações via JavaScript modificam o DOM, mas não o arquivo HTML original.

21.9 Mostrar, ocultar e destacar

Questão 31. Analise o código:

el.style.display = "none";
el.style.visibility = "hidden";

Qual é a diferença?

  1. São idênticas.
  2. display: none remove do fluxo (não ocupa espaço); visibility: hidden mantém o espaço reservado.
  3. visibility: hidden remove do DOM.
  4. display: none só funciona em parágrafos.
Ver resposta

Alternativa B. display: none faz o elemento deixar de ocupar espaço; visibility: hidden apenas o torna invisível, preservando o espaço.

Questão 32. Analise o código:

el.classList.toggle("destaque");

O que acontece a cada clique?

  1. A classe é adicionada sempre.
  2. A classe é removida sempre.
  3. A classe é adicionada se não existir e removida se existir.
  4. O elemento é removido.
Ver resposta

Alternativa C. toggle alterna: adiciona se ausente, remove se presente. É útil para alternar estados visuais via CSS.

21.10 Validação de formulários

Questão 33. Analise o código:

<input type="email" required>

O que acontece ao tentar enviar o formulário com o campo vazio?

  2. O navegador bloqueia o envio e exibe mensagem de validação.
  3. O campo é desabilitado.
  4. O valor é enviado como null.
Ver resposta

Alternativa B. required exige preenchimento; type="email" valida o formato. O navegador impede o envio se o campo estiver vazio ou inválido.

Questão 34. A validação HTML/JavaScript no navegador substitui a validação no servidor?

  1. Sim, é suficiente.
  2. Não; a validação no cliente pode ser contornada, portanto o servidor também deve validar.
  3. Sim, se usar required.
  4. Só substitui se o formulário usar POST.
Ver resposta

Alternativa B. A validação no cliente melhora a experiência do usuário, mas não substitui a validação no servidor, que é essencial para segurança.

form.addEventListener("submit", function(event) {
