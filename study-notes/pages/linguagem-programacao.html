2. O Paradigma Central: Intenção → Ação

Uma linguagem de programação não é apenas código; é a ponte estruturada que permite ao cérebro humano instruir a máquina a realizar tarefas específicas.

  • Vocabulário: palavras-chave que a máquina reconhece.
  • Sintaxe: regras gramaticais que organizam a lógica.

Do lado esquerdo, a intenção humana. Do lado direito, a ação computacional. No meio, o vocabulário e a sintaxe traduzem uma na outra.

3. Domínios da Programação

Devido à imensa diversidade de problemas no mundo real, linguagens com metas estruturais radicalmente diferentes foram desenvolvidas:

  • Aplicações Científicas — ex.: MATLAB, R, Python (NumPy).
  • Aplicações Comerciais — ex.: COBOL, SQL, Java.
  • Linguagens de Scripting — ex.: Python, JavaScript, Bash.
  • Programação de Sistemas — ex.: C, C++, Rust.
  • Inteligência Artificial — ex.: LISP, Prolog, Python (TensorFlow/PyTorch).

Compiladores vs. Interpretadores:

  • Compilador: tradução em lote (tudo ocorre antes da execução). Como traduzir um livro inteiro antes de publicá-lo.
  • Interpretador: tradução em tempo real (linha por linha, na hora). Como um intérprete traduzindo um discurso ao vivo.

Python é interpretado — o código é executado linha por linha pela Virtual Machine (CPython).

5. Por que Python?

  • Interpretada — não precisa compilar.
  • Altíssima legibilidade — filosofia focada no humano (Zen of Python / PEP-8).
  • Criada em 1989 por Guido van Rossum.
  • Devido a bibliotecas como NumPy e TensorFlow, tornou-se dominante tanto em Aplicações Científicas quanto em Inteligência Artificial.

7. Estruturas de Controle

7.1 Estrutura Condicional

A estrutura condicional, ou de decisão, auxilia a decidir que partes do programa devem ser executadas com base no resultado de uma condição. A base dessas decisões consistirá em expressões lógicas que permitam representar escolhas em programas.

if <condição>:
    bloco verdadeiro

if <condição>:
    bloco verdadeiro
else:
    bloco falso

Exemplos:

a = int(input("Primeiro valor: "))
b = int(input("Segundo valor: "))
if a > b:
    print("O primeiro número é o maior!")

idade = int(input("Digite a idade de seu carro: "))
if idade <= 3:
    print("Seu carro é novo")
else:
    print("Seu carro é velho")

8.5 Codificações de Caracteres

O computador não entende um texto. Os códigos são transformadores de texto em dados numéricos:

  • ASCII — American Standard Code for Information Interchange, padrão americano.
  • UNICODE — representa todos os caracteres de diversos idiomas (2 bytes por caractere).
  • UTF-8 (PEP-393) — simples, feito em ASCII e, quando precisa de um caractere do UNICODE, usa um caractere especial.

10. Funções

Uma função é uma parte de um programa (ou um módulo) que pode efetuar diversas operações computacionais: entrada, processamento e saída. É criada para cumprir uma tarefa particular.

Vantagens:

  • Modularização
  • Eliminação de redundância de código-fonte
  • Agilidade de manutenção
  • Reutilização de código-fonte
  • Coesão de código, mais organizado e gerenciável

Estrutura geral:

def nome_da_funcao(parametros):
    # corpo da função
    # alguma lógica de programação
    return valor_retorno

10.1 Formas de criação

FormaExemplo
Sem retorno, sem parâmetrodef mensagem(): ...
Sem retorno, com parâmetrodef somar(n1, n2): ...
Com retorno, sem parâmetrodef somar(): return r
Com retorno, com parâmetrodef somar(n1, n2): return r

Sem retorno, sem parâmetro:

def mensagem():
    print('Olá, tudo bem?')

def main():
    mensagem()

main()

Sem retorno, com parâmetro:

def somar(numero1, numero2):
    r = numero1 + numero2
    print("O resultado é", r)

def main():

    b = 7

main()

Com retorno, sem parâmetro:

def somar():
    n1 = int(input('Digite o primeiro número: '))
    n2 = int(input('Digite o segundo número: '))

main()

10.2 Parâmetros x Argumentos

Na chamada de uma função, são fornecidos valores concretos, chamados de argumentos, que serão repassados aos parâmetros.

Parâmetro = variável declarada na função (ex.: def somar(numero1, numero2)).
Argumento = valor passado na chamada (ex.: somar(a, b)).

11. Estruturas de Dados

Estrutura de dados é uma maneira de organizar e armazenar dados de forma que possam ser acessados e modificados eficientemente. Dentre outras: Lista, Tupla e Dicionário.

11.1 Lista

Coleção ordenada e mutável de elementos.

frutas = ["maçã", "banana", "laranja"]
print(frutas)  # ['maçã', 'banana', 'laranja']

frutas.append("uva")     # Adicionando
frutas.remove("banana")  # Removendo
frutas[0] = "morango"    # Modificando
print(frutas)  # ['morango', 'laranja', 'uva']

11.2 Tupla

Coleção ordenada e imutável. Vantagem: garante que os dados permaneçam constantes. Mais rápida que listas para leitura.

cores = ("vermelho", "verde", "azul")
print(cores)       # ('vermelho', 'verde', 'azul')
print(cores[1])    # verde

# cores[0] = "amarelo"  # TypeError: 'tuple' object does not support item assignment

11.3 Dicionário

Coleção não ordenada de pares chave-valor. As chaves podem ser de qualquer tipo imutável (strings, números, tuplas).

aluno = {'nome': 'João', 'idade': 20, 'curso': 'Engenharia'}
print(aluno)  # {'nome': 'João', 'idade': 20, 'curso': 'Engenharia'}

# Adicionando
aluno['nota'] = 9.5

# Removendo
del aluno['idade']

# Modificando
aluno['curso'] = 'Matemática'

# Métodos úteis
aluno.keys()    # chaves
aluno.values()  # valores
aluno.items()   # pares chave-valor

11.4 List Comprehension

Maneira concisa e eficiente de criar listas. Permite escrever loops for de forma mais compacta.

# Sem list comprehension
squares = []
for i in range(10):
    squares.append(i**2)
print(squares)

# Com list comprehension
squares = [i**2 for i in range(10)]
print(squares)
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

11.5 Loop for com funções auxiliares

zip() — combina duas listas:

nomes = ["Ana", "Bruno", "Carlos"]
idades = [25, 30, 35]

for nome, idade in zip(nomes, idades):
    print(f"{nome} tem {idade} anos.")
# Ana tem 25 anos.
# Bruno tem 30 anos.
# Carlos tem 35 anos.

enumerate() — adiciona um contador:

frutas = ["maçã", "banana", "cereja"]
for i, fruta in enumerate(frutas):
    print(f"{i}: {fruta}")
# 0: maçã
# 1: banana
# 2: cereja

filter() — filtra elementos com base em uma condição:

numeros = [3, 1, 4, 1, 5]
for num in filter(lambda x: x > 2, numeros):
    print(num)
# 3
# 4
# 5

11.6 Estrutura (Registro / Classe Simples)

Uma estrutura (ou registro) é uma estrutura de dados utilizada para definir variáveis que armazenam tipos de dados diferentes (heterogêneos). As variáveis que compreendem a estrutura são chamadas de membros, atributos ou campos.

class TipoAluno:
    matricula = 0
    nome = ''
    p1 = 0.0
    p2 = 0.0
    media = 0.0

def main():
    aluno = TipoAluno()
    aluno.matricula = int(input('Digite a matrícula: '))
    aluno.nome = input('Digite o nome do aluno: ')
    aluno.p1 = float(input('Digite a P1: '))
    aluno.p2 = float(input('Digite a P2: '))
    aluno.media = (aluno.p1 + aluno.p2) / 2

    print('Matrícula:', aluno.matricula)
    print('Nome:', aluno.nome)
    print('Média:', aluno.media)

main()

12. Arquivos e Persistência

Arquivos são uma excelente forma de entrada e saída de dados para programas. Um arquivo é uma área em disco onde podemos ler e gravar informações, acessado por nome.

12.1 Modos de abertura

ModoOperação
rLeitura
wEscrita; apaga o conteúdo se já existir
aEscrita; preserva o conteúdo se já existir (append)
bModo binário
+Atualização (leitura e escrita)

Os modos podem ser combinados: "r+", "w+",

Os modos podem ser combinados: "r+", "w+", "a+", "r+b", "w+b", "a+b".

A função open() retorna um objeto do tipo file. A função write() grava dados no arquivo. A função close() fecha o arquivo.

Ciclo obrigatório: Abrir → Ler → Fechar ou Abrir → Escrever → Fechar.

O fechamento é muito importante, pois cada arquivo aberto consome recursos do computador. Só o fechamento garante a liberação desses recursos e preserva a integridade dos dados do arquivo.

12.2 Escrevendo em arquivo

# Modo "w": apaga o conteúdo se já existir
arquivo = open('numeros.txt', 'w')
for linha in range(1, 21):
    arquivo.write('%i\n' % linha)
    # ou: arquivo.write(f'{linha}\n')
arquivo.close()
# Modo "a": preserva o conteúdo se já existir
arquivo = open('numeros.txt', 'a')
for linha in range(1, 11):
    arquivo.write(f'{linha}\n')
arquivo.close()

12.3 Lendo de arquivo

# Modo "r": abre apenas para leitura
arquivo = open('numeros.txt', 'r')
for x in arquivo.readlines():
    print(x)
arquivo.close()

# readlines() gera uma lista em que cada elemento é uma linha do arquivo

12.4 Trabalhando com dois arquivos

# Gravação de números pares e ímpares em arquivos diferentes
impares = open("impares.txt", "a")
pares = open("pares.txt", "a")

for n in range(1, 5):

12.5 Arquivo com estrutura

class TipoFuncionario:
    matricula = 0
    nome = ""
    salario = 0.0

def Cadastrar():
    arquivo = open('arq_Funcionario.txt', 'a')
    print('Cadastro de Funcionários...')
    for i in range(3):
        f = TipoFuncionario()
        f.matricula = int(input('Digite a matrícula: '))
        f.nome = input('Digite o nome: ')

    arquivo.close()

def Mostrar():
    arquivo = open('arq_Funcionario.txt', 'r')
    print('Matrícula\tNome\tSalário')
    for linha in arquivo.readlines():
        mat, nome, sal = linha.strip().split(" ")
        print(mat, '\t\t', nome, '\t', sal)
    arquivo.close()

12.6 Bloco with (gerenciador de contexto)

O bloco with é um gerenciador de contexto. Projetado para situações onde um recurso precisa ser configurado antes do uso e, em seguida, limpo após o uso. Vantagem: não esquece de fechar o arquivo.

# with já lida com o abrir e fechar do arquivo
with open("meu_arquivo.txt", 'w') as arquivo:
    arquivo.write("Olá, tudo bem?")

# Também funciona para ler
with open("meu_arquivo.txt", 'r') as arquivo:
    print(arquivo.read())

12.7 Arquivos JSON

Um arquivo JSON (JavaScript Object Notation) é amplamente utilizado para armazenar e transportar dados de maneira estruturada. Usos comuns:

  • Armazenamento de configurações — muitos aplicativos usam JSON para salvar configurações.
  • Troca de dados entre sistemas — APIs geralmente retornam respostas em JSON.
  • Persistência de dados — pode substituir arquivos CSV ou bancos de dados simples.
import json

dados = {"nome": "Maria", "idade": 25, "cidade": "São Paulo"}

# Escrevendo
with open("dados.json", "w") as arquivo:
    json.dump(dados, arquivo, indent=4)

# Lendo
with open("dados.json", "r") as arquivo:
    dados_carregados = json.load(arquivo)
    print(dados_carregados)

12.8 JSON ou XML?

CaracterísticaJSONXML
SintaxeObjetos e arrays, mais compactoBaseada em tags, mais verboso
FacilidadeMais simples de interpretarRequer mais processamento
CompatibilidadeMelhor integrado com APIs REST modernasMais comum em aplicações antigas (SOAP)
LegibilidadeMais limpo, sem fechamento de tagsMais detalhado e estruturado

Exemplo:

{
    "nome": "Maria",
    "idade": 25,
    "cidade": "São Paulo"
}
<usuario>
    <nome>Maria</nome>
    <idade>25</idade>
    <cidade>São Paulo</cidade>
</usuario>

12.9 Consumindo uma API que retorna JSON

import requests

# URL da API pública (exemplo)
url = "https://jsonplaceholder.typicode.com/users"

# Fazendo a requisição GET
resposta = requests.get(url)

# Verificando se a resposta foi bem-sucedida (código 200)
if resposta.status_code == 200:
    dados = resposta.json()
    for usuario in dados:
        print(f"Nome: {usuario['name']}, Email: {usuario['email']}")
else:
    print(f"Erro na requisição: {resposta.status_code}")

15. Type Hints

Type hints (ou anotações de tipo) foram introduzidos no Python 3.5. Permitem indicar os tipos esperados de variáveis, parâmetros e valores de retorno de funções. Não mudam o funcionamento do código, mas ajudam:

  • Na documentação do código
  • Em ferramentas de análise estática (ex.: IDEs)
  • Na legibilidade e manutenção

15.1 Variáveis

idade: int = 25
nome: str = "Fatec"
ativo: bool = True
altura: float = 1.75

numeros: list[int] = [1, 2, 3]
dados: dict[str, int] = {"a": 8, "b": 3}
coordenadas: tuple[float, float] = (10.5, 20.3)

from typing import Optional
idade_opcional: Optional[int] = None  # ausência de valor

15.2 Funções

# SEM tipagem — implícita (tipagem dinâmica)
def saudacao(nome, idade):
    return f"Olá {nome}, você tem {idade} anos."

# COM tipagem — explícita
def saudacao(nome: str, idade: int) -> str:
    return f"Olá {nome}, você tem {idade} anos."
# Função que recebe uma lista de floats e retorna um float
def media(notas: list[float]) -> float:
    return sum(notas) / len(notas)

def distancia(x1, y1, x2, y2):
    d = (((x2 - x1) ** 2) + ((y2 - y1) ** 2)) ** (1/2)
    return d

def main():
    coord_x1 = int(input("Digite a coordenada x1: "))
